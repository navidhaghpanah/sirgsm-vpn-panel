## Sirgsm VPN v3.5.0

Full rebrand of the panel as **Sirgsm VPN**, with the official gold/black identity and logo.

- Panel version is now **3.5.0** (shown in the UI)
- Removed third-party donate buttons (Buy Me a Coffee, NOWPayments, and donate.sanaei.dev) from the README, panel, docs, and GitHub funding file
- Install and update scripts now pull releases from [navidhaghpanah/sirgsm-vpn-panel](https://github.com/navidhaghpanah/sirgsm-vpn-panel) on the `main` branch

### Install

```bash
bash <(curl -Ls https://raw.githubusercontent.com/navidhaghpanah/sirgsm-vpn-panel/main/install.sh)
```

### Update

```bash
bash <(curl -Ls https://raw.githubusercontent.com/navidhaghpanah/sirgsm-vpn-panel/main/update.sh)
```
