# بکاپ و مهاجرت

## بکاپ / ریستور

**پنل > تنظیمات > بکاپ:**

- **دانلود بکاپ (DB)**: یک کپی سازگار از `panel.db` دانلود می‌کند.
- **ریستور**: آپلود فایل `.db` — اول از دیتابیس فعلی بکاپ گرفته می‌شود، بعد جایگزین می‌شود (پنل + Xray ری‌استارت).
- **بکاپ دستی به ربات**: فایل دیتابیس را به ادمین در تلگرام می‌فرستد.
- **بکاپ خودکار**: هر ۲۴ ساعت (قابل تنظیم) اگر توکن ربات + آیدی ادمین ست باشد، بکاپ به ربات ارسال می‌شود. فایل‌ها در `/opt/sirgsm-panel/backups/` نگه داشته می‌شوند (۷ تای آخر).

## مهاجرت کاربر (خروجی / ورودی)

**تب کاربران > خروجی / ورودی:**

- **خروجی (Sirgsm)**: JSON با `email, inbound, uuid, password, traffic_limit (بایت), expiry (timestamp), ip_limit, enable, note, up, down` — مدت و حجم حفظ می‌شود.
- **خروجی (Marzban)**: JSON سازگار با Marzban (`username, proxies, expire, data_limit, status, note`) — مستقیم در Marzban ایمپورت کن.
- **ورودی**: آپلود JSON (فرمت Sirgsm یا Marzban) — کاربرها با انقضا و حجم ساخته می‌شوند. ایمیل‌های تکراری رد می‌شوند.

مثال (فرمت Sirgsm):

```json
[{"email":"ali","inbound":"vless","uuid":"...","traffic_limit":10737418240,"expiry":1799999999,"ip_limit":2,"enable":true}]
```

`traffic_limit` به بایت است (۱۰ گیگ = 10737418240)، `expiry` timestamp یونیکس است (۰ = نامحدود).
