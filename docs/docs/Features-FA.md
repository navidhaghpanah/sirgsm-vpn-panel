# قابلیت‌ها

## پروتکل‌ها و ترنسپورت‌ها

| اینباند | پورت | ترنسپورت‌ها |
|---|---|---|
| VLESS | 443 | Reality+TCP، Reality+gRPC، TLS+WS، TLS+gRPC، TLS+TCP، TCP، WS |
| Trojan | 8443 | Reality+TCP، TLS+WS، TLS+gRPC، TLS+TCP، TCP |
| Shadowsocks 2022 | 8388 | TCP/UDP |
| VMess | 2096 | Reality+TCP، TLS+WS، TLS+gRPC، TCP، WS |

ترنسپورت را در **پنل > تنظیمات > ترنسپورت‌ها** عوض کن (برای TLS اول باید گواهی SSL گرفته باشی).

## کاربران

- انقضا (روز)، سقف حجم (گیگ)، سقف IP همزمان، تعداد آنلاین، وضعیت (فعال/غیرفعال/منقضی/پر شده)، عملیات گروهی.
- QR کد (لینک + اشتراک)، لینک اشتراک با **لندینگ‌پیج** (مرورگر → جزئیات اکانت؛ کلاینت VPN → متن خام؛ `/raw` برای خام).

## سرور و شبکه

CPU، RAM، دیسک، آپ‌تایم، ورودی/خروجی شبکه + سرعت، جزئیات هر اینترفیس، ترافیک VPN، وضعیت Xray/Warp/Asterisk.

## Warp و routing

خروجی Cloudflare WARP برای یوتیوب/گوگل/اوپن‌ای‌آی/تلگرام + قوانین routing سفارشی با preset.

## L2TP / IKEv2

IPsec (strongswan) + L2TP (xl2tpd)، PSK از تنظیمات، اکانت‌های PPP جدا، پورت‌های UDP 500/4500/1701.

## ربات، بکاپ، مهاجرت، آپدیت

- ربات تلگرام: `/add /list /links /status /l2tp /version /del /reset /enable /disable` (توکن در تنظیمات).
- بکاپ: دانلود دیتابیس، ریستور، بکاپ خودکار هر ۲۴ ساعت به ربات.
- مهاجرت: خروجی/ورودی JSON (فرمت Sirgsm + Marzban) با حفظ مدت و حجم.
- آپدیت: بررسی ریلیزهای گیت‌هاب، آپدیت یک‌کلیکی.
