## Quick start

```bash
curl -fsSL https://raw.githubusercontent.com/navidhaghpanah/sirgsm-vpn-panel/main/install.sh | bash
```

Panel: `http://YOUR_DOMAIN:2053/YOUR_SECRET_PATH/` (admin / generated password in `/root/sirgsm-panel.txt`).

Bot: [@mahsah_ai_bot](https://t.me/mahsah_ai_bot) — set token in Panel > Settings.
